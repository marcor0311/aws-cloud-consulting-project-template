# AWS Cloud Consulting Project Template

Plantilla para crear un repositorio independiente por proyecto de consultoría
AWS. Centraliza la documentación y organiza el trabajo desde el descubrimiento
hasta el cierre, con una estructura inicial para trabajar con Codex.

Cada proyecto se crea con **Use this template** y completa sus entregables a
medida que avanza por las seis fases:

1. [Descubrimiento y preparación](docs/01-discovery/README.md)
2. [Priorización](docs/02-board/README.md)
3. [Arquitectura](docs/03-architecture/README.md)
4. [Costos](docs/04-finops/README.md)
5. [Implementación y operación](docs/05-engineering/README.md)
6. [Informe ejecutivo y cierre](docs/06-executive/README.md)

El código de infraestructura se incorpora en [infra/](infra/README.md) y las
validaciones en [tests/](tests/README.md). Las instrucciones para Codex están en
[AGENTS.md](AGENTS.md).
