# 01. Descubrimiento y preparación

**Responsable:** Engagement Manager.

## Propósito

Reunir el contexto necesario para evaluar la propuesta con dirección ejecutiva.
Esta fase ocurre antes de crear el repositorio del proyecto. Sus insumos aprobados
se incorporan aquí cuando se autoriza continuar.

## Insumos

Solicitud inicial, referencias a reuniones, notas y antecedentes disponibles.
Los datos maestros de empresa y contactos se consultan mediante el backend.

## Trabajo y entregables

- Documentar necesidad, alcance, requisitos, restricciones y criterios de éxito.
- Registrar los supuestos de presupuesto y plazos que deben evaluarse.
- Incorporar el resumen ejecutivo, la presentación y el guion aprobados.
- Referenciar las fuentes y los documentos con acceso restringido.

## Criterio de entrega

El Engagement Manager valida que la propuesta tenga contexto suficiente para una
decisión. La dirección ejecutiva la evalúa en
[02-board](../02-board/README.md). Esta guía no acredita esa aprobación.
