# 02. Priorización

**Responsable:** dirección ejecutiva.

## Propósito

Conservar la decisión que autoriza y delimita el proyecto. La decisión de
continuar permite crear el repositorio e iniciar arquitectura.

## Insumos

Paquete aprobado de [descubrimiento](../01-discovery/README.md), con propuesta,
presupuesto, plazos y referencias a la reunión ejecutiva.

## Trabajo y entregables

- Registrar la decisión, su fecha, responsables y justificación.
- Definir prioridad, presupuesto autorizado y condiciones que deben cumplirse.
- Identificar al arquitecto asignado y referenciar la tarea inicial.
- Conservar las referencias a los materiales presentados y a la aprobación.

## Criterio de entrega

La aprobación humana es verificable y la tarea de
[arquitectura](../03-architecture/README.md) tiene responsable e insumos.
Una decisión pendiente o negativa no habilita el trabajo posterior.
