# 06. Informe ejecutivo y cierre

**Responsable:** Engagement Manager.

## Propósito

Consolidar los resultados para dirección y registrar la aceptación del cierre.

## Insumos

Entrega de [ingeniería](../05-engineering/README.md),
[costos validados](../04-finops/README.md), decisiones y referencias a evidencias.
El backend aporta Lead Time, Process Time, esperas y retrabajo de las fases.

## Trabajo y entregables

- Preparar el informe ejecutivo y su PDF con resultados y siguientes pasos.
- Comparar la entrega y los costos previstos con el alcance y presupuesto.
- Explicar las limitaciones y los riesgos que requieren seguimiento.
- Incorporar métricas consultadas al backend, indicando su alcance y período.
- Registrar la revisión, aprobación y presentación del Engagement Manager.

## Criterio de entrega

El informe aprobado referencia la entrega técnica, los costos y las evidencias.
La aceptación del cierre tiene responsable y referencia verificable. El backend
registra el cierre; esta guía no implica que el proyecto esté terminado.
