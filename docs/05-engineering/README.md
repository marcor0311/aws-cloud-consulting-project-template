# 05. Implementación y operación

**Responsable:** Cloud Infrastructure Engineer.

## Propósito

Implementar y validar el diseño aprobado, y dejar instrucciones suficientes para
reproducir la entrega y operarla.

## Insumos

Arquitectura aprobada, versiones de baselines y
[entrega de FinOps](../04-finops/README.md), con issue, rama y commits asociados.

## Trabajo y entregables

- Implementar en [infra/](../../infra/README.md) los recursos del diseño.
- Incorporar las pruebas y políticas aplicables en
  [tests/](../../tests/README.md), con comandos reproducibles.
- Documentar configuración, ejecución, operación y reversión o limpieza.
- Registrar la validación local con el entorno, versión y resultados obtenidos.
- Preparar el PR final, enlazando arquitectura, costos y evidencias.

## Criterio de entrega

Los resultados cumplen la tarea y el arquitecto aprueba el PR técnico. La entrega
integrada referencia los commits y las limitaciones pendientes. El backend avisa
al Engagement Manager para preparar el
[informe ejecutivo](../06-executive/README.md).
