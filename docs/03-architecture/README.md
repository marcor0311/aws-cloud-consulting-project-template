# 03. Arquitectura

**Responsable:** Cloud Solutions Architect.

## Propósito

Convertir la necesidad aprobada en un diseño AWS que permita estimar costos e
implementar la solución.

## Insumos

[Descubrimiento](../01-discovery/README.md),
[decisión ejecutiva](../02-board/README.md) y tarea asignada al arquitecto.

## Trabajo y entregables

- Documentar el diseño, región, recursos, dependencias y supuestos de uso.
- Crear el diagrama AWS como código y su representación legible.
- Justificar las decisiones relevantes, alternativas y restricciones.
- Consultar `aws-cloud-consultant-baseline-modules` y registrar la versión o
  commit aprobado de cada módulo seleccionado.
- Definir las comprobaciones de seguridad y políticas aplicables al diseño.

## Criterio de entrega

El arquitecto aprueba el PR técnico. La tarea de
[FinOps](../04-finops/README.md) referencia el commit de diseño, diagrama,
recursos, región, módulos, supuestos y presupuesto autorizado.
El backend registra la entrega a la siguiente persona responsable.
