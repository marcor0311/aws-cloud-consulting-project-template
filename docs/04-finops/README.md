# 04. Costos

**Responsable:** FinOps Analyst.

## Propósito

Validar que el costo previsto de la arquitectura sea coherente con los supuestos
de uso y el presupuesto autorizado.

## Insumos

Commit aprobado de [arquitectura](../03-architecture/README.md), recursos,
región, versiones de módulos, supuestos y presupuesto.

## Trabajo y entregables

- Registrar los supuestos de estimación y las aclaraciones del arquitecto.
- Generar el enlace real de AWS Pricing Calculator para la propuesta.
- Crear el Excel con fórmulas, costos por recurso, proyecciones y escenarios.
- Documentar la validación y resolver diferencias antes de entregar.

## Criterio de entrega

FinOps confirma la coherencia del enlace, Excel y presupuesto. La tarea de
[ingeniería](../05-engineering/README.md) referencia esos entregables y el commit
de arquitectura. Se conservan aquí como fuente para las fases siguientes.
El backend registra el handoff confirmado; un comentario aislado no lo completa.
