# Validaciones del proyecto

**Responsable:** Cloud Infrastructure Engineer, con criterios del arquitecto.

Esta área comienza sin pruebas de una solución. Las comprobaciones iniciales de
documentación y secretos están descritas en el [README principal](../README.md).

## Al incorporar código

- Añadir pruebas de los requisitos y de los fallos relevantes para la solución.
- Incluir las validaciones de infraestructura, seguridad y políticas aplicables.
- Documentar requisitos, comandos y resultados esperados para reproducirlas.
- Actualizar el workflow con esos comandos y sus condiciones de ejecución.
- Registrar evidencias de validación en
  [ingeniería](../docs/05-engineering/README.md), con entorno y versión probada.

Un check de documentos no acredita que la infraestructura funcione. Los PRs deben
identificar qué se validó y las limitaciones que permanecen pendientes.
